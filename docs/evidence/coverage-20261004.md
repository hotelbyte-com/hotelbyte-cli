## 结论

1. **145/145 curated 端点全部命中 2026-10-04 UAT live 目录**——无死指针、无凭空端点。
2. curated 面 145 端点 ≈ 目录的 7.6%（145/1912），其余 **100% 可达性由 `api call` 反射透传兜底**；
   `hbcli api catalog` / `api describe` 可在线枚举/自省任意方法（含 operationType 读写分类与 `--confirm` 守卫）。
3. `user/tenant`（127 方法）是最大单一服务面，curated 只取 identity/marketplace 高频 13 个；
   长尾（如角色成员管理、entity 细粒度配置）继续走 `api call`，不设 curated（如无必要，勿增实体）。
4. 既有 8 组（auth/search/trade/orders/team/account/products/catalogs + api/mcp/skill/view/fx 等）不在本表，
   属 PR #39 / #42 交付面，本分支完整继承（分支含 `origin/feat/portal-modules` 全部提交）。
